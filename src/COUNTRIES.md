# Country snapshot v1

The four geography games share `country-snapshot.json`, validated at module load by `countries.ts`. Population and land area are frozen World Bank WDI **2023** values retrieved 2026-10-29. Each row links to its exact indicator request. Population means de facto mid-year residents, regardless of citizenship or legal status. Land area excludes inland water, continental shelf claims and exclusive economic zones. Both fields are rounded to whole units; the original API has fractional land areas for some small countries. No facts are fetched during play.

Definitions: [population](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/SP.POP.TOTL), [land area](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/AG.LND.TOTL.K2). Names/capitals were checked against the [World Bank country API](https://api.worldbank.org/v2/country?format=json&per_page=400). Display spelling normalizes Kiev to Kyiv and N'Djamena to N’Djamena. Jakarta is the snapshot capital for Indonesia; this question bank represents the pinned reference period, not a live capital-transition feed.

Original stripe geometry was checked against the [UN Vienna Protocol national flag reference](https://www.unvienna.org/protocol/uploads/res/generic-information_html/A-Z_Flags_external.pdf). Equal sub-bands encode Latvia's 2:1:2 bands without losing proportions. Belgium uses 13:15 height:width; Monaco uses 4:5. Flags retain individual aspect ratios and rotate with the entire far-facing copy. The supported country pool deliberately omits flags needing emblems. The UN publication is a visual design reference, not a normative specification for screen RGB values.

Geographic region labels are broad teaching groups (Europe, Africa, Asia), not World Bank administrative or income regions. Familiarity is explicit, provisional teaching metadata. Capital confusion lists are curated provisional distractors, including Budapest/Bucharest and Baltic capitals; they are not measured player error rates. Flag confusions list other band flags of the same axis, preferring the same band count. Difficulty never changes factual tags or values.

Comparison pair pools use ratios >=3 with familiar countries for easy, 1.7–3 for medium, <1.7 for hard, and adjacent snapshot ranks for insane. Exact ties are excluded. These thresholds and static hold times are provisional presets, not historical reference measurements. Updating this version is an intentional data change: update expected-pair tests with it.
